# olist-sql

Здесь я решаю на SQL 14 вопросов по данным бразильского маркетплейса Olist. В данных около 99 тыс. заказов за 2016-2018 годы, всего 9 таблиц. Всё считалось в DuckDB.

Данные можно скачать на Kaggle https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Как запустить

Нужно скачать CSV с Kaggle в папку data/. После этого достаточно выполнить

```
duckdb olist.duckdb < load_olist.sql
duckdb olist.duckdb < queries/q13_cohorts.sql
```

Вместо q13_cohorts.sql можно подставить любой файл из папки queries. В первой строке каждого файла написан вопрос.

## Какие инструменты я использовал

В задачах 1-9 используются JOIN, GROUP BY, HAVING, CASE и FILTER. А именно, там считаются доля повторных покупателей, самые прибыльные категории, связь опозданий доставки с оценками, способы оплаты, самые крупные продавцы, доля доставки в цене товара, время доставки по штатам и отмены заказов по месяцам.

В задачах 10-14 используются оконные функции LAG, ROW_NUMBER и NTILE. Если быть точнее, то там считаются рост выручки по месяцам, время до второго заказа, топ-3 товара в каждой категории, когорты покупателей по месяцу первой покупки и доля выручки у самых крупных продавцов.

## Что получилось интересного

- Повторных покупателей всего 3,12%. Вернувшиеся 2997 человек делали второй заказ в среднем через 80 дней. При этом у половины из них второй заказ был в течение 28 дней. То есть среднее завышают несколько покупателей, которые вернулись через очень долгий промежуток времени.
- Опоздание доставки сильно портит отзывы. А именно, средняя оценка у опоздавших заказов 2,57, а у остальных 4,29. Чаще всего опаздывают в штатах CE (15,3%), BA (14,0%) и RJ (13,5%).
- 10% продавцов (310 из 3095) дают 67,6% всей выручки.
- Я разбил покупателей на когорты по месяцу первой покупки. Доля вернувшихся падает с 7,6% (январь 2017) до 0,8% (август 2018). Но это довольно нечестное сравнение, потому что у поздних когорт было меньше времени вернуться до конца сбора данных.
- В месячной выручке нет ноября 2016. Поэтому рост для декабря 2016 я не считаю, чтобы не сравнивать его с октябрём.
